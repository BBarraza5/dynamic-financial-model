# dynamic-financial-model
**Overview**

Developed a dynamic financial forecasting model in Microsoft Excel to project revenue, expenses, profitability, and cash flow over a 5-year period.

**Features**
Revenue forecasting
Expense projections
Income statement modeling
Cash flow analysis
Scenario analysis
KPI dashboard
**Tools Used**
Microsoft Excel
Financial Modeling
Forecasting Techniques
Scenario Analysis
**Key Insights**
The model allows users to adjust assumptions and instantly evaluate the impact on profitability and cash position.
